What do the three controls mean?

Shared boost: every proton emitted by a given clump receives the same Lorentz boost: one speed and one direction, shared by that clump's daughters. Their individual thermal momenta still differ. Different clumps can have different boosts.

Azimuth decohered: start from those same lab particles and independently randomize each daughter's azimuth φ around the beam axis. Keep its pT, pseudorapidity η, energy, identity and acceptance unchanged, with the identical background. This comparison removes the clump's azimuthal alignment; pair angles and q_inv can change. “Decohered” means angular scrambling here, not quantum decoherence.

Event mixed: generate each source proton from an independent donor source. Each donor samples T, boost speed and direction from the same configured distributions, then receives its own thermal momentum and full Lorentz boost. This removes shared longitudinal motion and other common-source correlations while matching the one-particle ensemble across many events. Emitted n matches the shared source; accepted counts and individual-event pT/y spectra can differ. The background stays identical. This is a synthetic mixed reference, not a permutation of the current event's rapidities.

How the clump explorer works

What does common boost beta control?

β = v/c is the clump source's speed relative to the laboratory. β = 0.4 means 40% of the speed of light. The direction comes from the collective-direction control; beta sets its magnitude.

First, protons are sampled with individual thermal momenta in the source's rest frame. Every daughter of that clump then receives the same Lorentz boost vector. Changing beta reapplies that boost to the same rest-frame sample and keeps the pinned background. Individual proton velocities still differ.

β = 0: no collective source motion; protons still have thermal motion.

β = 0.4: common source motion at 0.4c. A proton initially at rest in the source would have about 0.410 GeV momentum along the boost direction.

Larger β: stronger common motion. Lab momenta, angles and the number of daughters passing the lab cuts can change. β stays below 1; this explorer caps it at 0.95.

In natural units, γ = 1/√(1−β²) and E = γ(E* + β⃗·p⃗*). A full Lorentz transformation is applied to all four components [E, px, py, pz].

Temperature T controls the random thermal motion in the rest frame. Beta controls the common source motion. Emitted n is the number generated before lab cuts; accepted n can be smaller.

Shared boost and azimuth decohered

Shared boost is the original clump: the boost speed and direction are shared by all daughters of each clump. With several clumps, each has its own sampled boost.

Azimuth decohered starts from those same lab particles and independently scrambles each daughter's φ around the beam axis. It preserves pT, pseudorapidity η, energy, particle IDs and acceptance, and uses the identical background. It removes the clump's azimuthal alignment; pair angles and q_inv can change. This is an angular control, not quantum decoherence.

Event mixed draws each proton from an independent synthetic donor event with the same configured T/speed/direction distributions and the same lab cuts. Full four-vectors are generated consistently. Shared longitudinal boosts (for isotropic 3D directions) and shared fluctuating source parameters are removed. One-particle distributions match in the ensemble, not particle by particle or necessarily in one displayed event. Emitted count matches; accepted count may differ. Background stays pinned.

Permuting rapidities within one clump would leave its set of pairwise |Δy| unchanged; drawing rapidities uniformly would impose a different spectrum. Independent donor sources give a physical mixed reference instead. With fixed T, fixed beta and transverse directions, there is no shared longitudinal boost to remove, so the difference may be small. In event-mixed rest inspection, each point is in its own donor rest frame; there is no common source frame or direction arrow. Every donor is distinct, so no same-source pair overlay is shown.

New control draws redraws mixed donors and azimuth scrambling through the control revision while preserving the shared source and background. Older loaded recipes retain their saved variant list; tick Include event-mixed control to add the mixed reference.

What stays fixed when I edit controls?

With Auto update on, physical edits request an updated event. Signal edits retain the exact pinned background. Beta and direction changes preserve the rest-frame thermal sample; acceptance changes only change which generated particles pass. New clump redraws that source sample. Local composition, color and camera controls reuse the current event.

The phi-scrambled and event-mixed controls are opt-in. Tick their separate checkboxes in the source panel to generate them. Both start off. Loaded recipes restore the controls saved in their variant list; switching a checkbox preserves the shared source and pinned background.

Why can a red point disappear as beta changes?

A fixed daughter keeps its rest-frame momentum, but its laboratory momentum changes with beta. A transverse boost can reduce its pT first and increase it later, carrying it out of and back into the eta/pT cuts. Rejected daughters are hidden by default; enable Rejected daughters to see them as gray truth ghosts. For seed 42 with the default source, daughter c0:d4 leaves |eta| < 1 near beta 0.18 and returns near 0.69, at a different lab momentum.

The 3D box is a fixed coordinate guide, not a clipping volume. Accepted points can also leave the camera viewport as their momenta grow. Each panel separately reports lab rejections and accepted source-point centers outside the camera. Fit compared union explicitly reframes the complete union; beta changes never automatically move the camera. The viewport count does not detect points obscured by another particle. Replay is an optional illustration, not the physical path of a changing-beta particle.

Colors and replay

Red protons belong to the clump (or independent donors in the mixed panel) and green protons to the background in Clump / background · truth coloring. Origin is simulation truth; choose Species · origin hidden for a neutral comparison.

Replay on change is off initially. Tick it to replay after a changed event arrives, or use Replay illustration manually. Replay is a presentation of momentum vectors, not emission positions, a lifetime or a physical trajectory. Statistics always describe the final accepted event.

Background files and recipes

The explorer generates signal clumps live. New backgrounds from toys/boltzmann/generate_canonical_h5.py use the exact same massive 3D thermal sampler for pions, kaons and protons, with each species' mass and one common input T. Background particles are independent, with beta zero; signal daughters receive their clump's common boost. Equal input temperatures need not give identical lab spectra when boosts differ.

The Background T metric shows the recorded input temperature, not a fitted slope. The new generator fixes it across events; centrality controls geometry and emitted multiplicity. Lab acceptance can reduce the stored count, without refilling. This changes the old spectra and multiplicity calibration. Older Gamma-pT datasets retain their old law and show an unrecorded T.

The default catalog searches toys/boltzmann/canonical-output/ and the legacy toys/boltzmann/output/, relative to the checkout. --data-dir overrides those defaults; each directory includes its output/ subfolder and the option also accepts an exact file. Source-only mode needs no background.

For a small background sample, run from the checkout root:

python toys/boltzmann/generate_canonical_h5.py \
  --settings bes --n-events 1000 --temperature-gev 0.1

Reload the page to find the new file in the dataset selector. The generator runs separately; slider changes do not generate disk datasets. Existing output files are protected from replacement unless --overwrite is explicitly supplied.
